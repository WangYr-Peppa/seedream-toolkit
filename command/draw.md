用户描述：$ARGUMENTS

**所有出图都走这一条统一流程**（原 `/draw`、`/edit`、`/qc`、`/bestof` 已合并到这里）：

1. 按 `seedream-prompt-compiler` 清理提示词（剥元指令 / 抽参数 / 去堆叠；**默认不补全**）。
2. 🚦 **内容安全预检**：对照 `seedream-prompt-compiler/CONTENT_SAFETY.md` 判定树（硬红线 → 拒绝；灰区 → 说明风险、交用户确认）。
3. 🚦 **Ask Gate A**：展示「编译后提示词 + diff + 风险」。
4. 🚦 **Ask Gate B（逐项分列提问）**：
   - **比例** · **参考图**（**有 → 图生图 / 编辑**）· **张数**（**4 → best-of-N 挑最佳**）· **模型** · **分辨率** · **质检**（日常 / 带自检）
5. 用最终参数**自动跑一次 `--dry-run`**（校验参数 + 预估费用），把结果并进放行确认。
6. **获准后**才出图；**未获确认不得生成、不得自行重抽。**
7. 按你的选择执行：
   - 参考图 = 有 → 加 `-i <图>`（编辑 / 融合）
   - 张数 > 1 → 生成后交 `@observer` **排序挑第一**
   - 质检 = 带自检 → 走 `seedream-qc` 闭环（**仅此时**允许自动重抽，封顶 2 次）
8. 交付图片**本地路径**（脚本成功后会自动预览）。

> 提示：想"只试算不花钱"，第 5 步的 `--dry-run` 本身就零成本；想跳过闸门直出，只有你**显式**说"直接出"才行。
