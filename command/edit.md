指令：$ARGUMENTS

1. 明确参考图（本地路径或 URL；可多张 = 融合）。提示词用**自然语言编辑指令**（如“把背景换成雨夜街道”“去掉帽子”），**不要负向词**。
2. 按 `seedream-prompt-compiler` 处理；🚦 **走 Ask Gate**：确认提示词 + 出图参数（比例 / 张数 / 模型 / 分辨率）。**精确编辑 / 高保真建议 `pro`。**
3. 获准后：`generate_image.py -i "<参考图>" -p "<指令>"`（默认 `5.0-flash` + `1.5K`）。
4. 交付图片本地路径（脚本会自动预览）。
