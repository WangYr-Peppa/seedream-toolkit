# 火山方舟 Seedream 文生图

通过火山引擎方舟标准接口调用豆包 Seedream 系列模型生成图片。
**只有当用户意图是"生成/创作一张图片"时才使用本技能**；读取或分析已有图片请用 `read` / @observer。

## 前置条件

- 环境变量 `ARK_API_KEY`（火山方舟控制台「API Key 管理」创建，标准按量付费 Key）已设置。
- 该 Key 对应账号已在方舟控制台**开通**要用的 Seedream 模型。
- 本机 `python` 可用（脚本仅用标准库，无需额外依赖）。

若脚本报 `ARK_API_KEY is not set`，提示用户设置（PowerShell）：

```powershell
[Environment]::SetEnvironmentVariable("ARK_API_KEY","<key>","User")
```

设置后需**新开终端 / 重启 opencode** 才会生效。

## 用法

脚本位置（相对本技能目录）：`scripts/generate_image.py`

基础文生图：

```bash
python "<skill_dir>/scripts/generate_image.py" -p "一只戴着墨镜的橘猫，坐在海边，日落，超写实" -f cat -o ./output
```

常用参数：

| 参数 | 说明 | 默认 |
|---|---|---|
| `-p/--prompt` | 提示词（必填，中英文均可，建议 ≤300 汉字） | — |
| `-f/--filename` | 输出文件名（不含扩展名） | `seedream` |
| `-o/--out` | 输出目录 | 当前目录 |
| `-m/--model` | 模型别名或原始 ID（见下） | `doubao-seedream-5-0-flash-260915` |
| `-s/--size` | `1K`/`1.5K`/`2K` 或 `2048x1152`（5.0-pro 最高 2K，**无 4K**） | `1.5K` |
| `-a/--aspect` | `1:1 4:3 3:4 16:9 9:16 3:2 2:3 21:9`（按 `--size` 档位自动算像素） | 无 |
| `-i/--image` | 参考图路径/URL，可重复；单张=图生图，多张=多图融合（≤10 张） | 无 |
| `--prompt-mode {standard,fast,off}` | Ark 内置提示词优化模式（`fast` 目前确认**仅 pro** 支持；flash/lite/4.5 仅 standard） | `standard` |
| `--seed` | 随机种子，复现结果 | 随机 |
| `--no-watermark` / `--watermark` | 关闭/开启 AI 水印 | 关闭 |
| `--sequential --max-images N` | 连贯组图（多图 = 多倍费用） | 关 |
| `--web-search` | 联网搜索增强（**仅 5.0-lite 支持**；pro/flash 不支持） | 关 |
| `-n/--n N` | 一次出 N 个变体抽卡（配合 `--seed` 用 seed, seed+1…）；**成本 × N** | `1` |
| `--save-meta` | 在每张图旁写 `.txt` 元数据（提示词/参数/seed）便于复现 | 关 |

模型别名（本机 cn-beijing 账号 2026-10 实测可用性）：

- `5.0-flash` → `doubao-seedream-5-0-flash-260915` ✅ 可用（默认，最便宜）
- `5.0-pro` → `doubao-seedream-5-0-pro-260628` ✅ 可用（质量 / 编辑）
- `4.0` → `doubao-seedream-4-0-20260415` ⭕ 可开通（4K 用）
- `5.0-lite` / `4.5` / `5.0` / `3.0-t2i` → 各自旧 ID ❌ 本机 `NotFound`（未上线 / 已下线）

> **模型可用性提示**：调用未开通的模型会返回 `ModelNotOpen` —— 需先在火山方舟控制台「开通管理」激活。实测（2026-10）`flash`、`pro` 通常可用；`lite` / `4.5` / `3.0` 在部分账号/区域返回 `NotFound`（未上线或已下线）。**以控制台或 `/api/v3/models` 的 `status`（空=可用）为准。**

## 图生图 / 图像编辑（把已有图片交给模型）

用 `-i/--image` 传入参考图（本地路径或 URL；本地文件脚本会自动转 base64）：

```bash
# 单图 = 图生图 / 编辑：按提示词修改这张图
python "<skill_dir>/scripts/generate_image.py" -p "把背景换成雨夜霓虹街道" -i ./original.jpg -f edited -m 5.0-pro

# 多图 = 多图融合 / 角色一致性：用参考角色生成新场景
python "<skill_dir>/scripts/generate_image.py" -p "同一个女生坐在教室里看书" -i ./char.png -f newscene
```

要点：

- **编辑类提示词用自然语言指令**（官方风格）：“把帽子去掉”“把背景换成雨天”“让她看向镜头”。**不要用负向词**（官方不支持）。
- **单图=改这张图；多图=融合/一致性**；是“编辑”还是“生成新图”**由提示词决定**。
- **模型**：flash / 4.0 / 4.5 / 5.0-pro 都支持图生图与编辑；**仅 pro** 另有“坐标/框选交互编辑”与“图层拆分”（脚本暂未暴露这两个高级参数）。
- **计费**：输入图按“输入图 0.02 元/张（首张免费）”另计（pro）；输出仍按 张×分辨率。
- **尺寸**：可省略 `-s` 让输出跟随输入图，或用 `-s` 指定输出分辨率。本地图会转 base64 data URL 上传；接口也接受公网 URL。

| `4.5` | 4K | 仅 standard | 未证 | ✅ | 上一代增强 |

选型建议：

- **日常 / 反复试稿（默认）** → `5.0-flash`（0.12 元/张，新一代质量 + 最便宜 + 更快）。
- **定稿 / 精细局部修改** → `5.0-pro`（0.30–0.60 元/张，交互编辑、图层拆分）。

**实测价格表（火山方舟控制台，2026-10，按张计费）**：

| 模型 | 单价 |
|---|---|

## 提示词

- **Ark 内置优化**：脚本默认 `--prompt-mode standard`（模型侧自动优化）；`fast`（仅 pro）提速略降质，`off` 关闭。
- **规范化用 `seedream-prompt-compiler`**：只做**清理**（剥元指令 / 抽参数 / 去堆叠 / 否转正 / 控长度），**默认不补全**。提示词写法与避坑详见该 skill。

> 🚦 **出图前先确认提示词（Ask Gate）**：若提示词是**清理器编译出来的**、或来自用户的**模糊描述**，**生成前**要用提问工具把「成品提示词 + 一句话 diff + 风险」交用户过目，**获准才出图**（详见 `seedream-prompt-compiler` 的 Ask Gate）。**提示词仍是“AI 写的”**——它可能把模糊诉求直译成画面词、或改变结构（实测“脚部交代清楚”→“脚趾画清楚”→ 女孩丢袜子），出图才发现跑偏就白花钱。用户显式说“直接出”才跳过。

## 输出的处理

- 脚本打印 `SAVED: <绝对路径>`，表示图片已下载到本地（**必须本地保存**：接口返回的 URL 仅 24 小时有效）。
- 生成后如需检查效果，用 `read` 读取该图片文件（或派 @observer 分析画面）。
- 把最终保存路径告知用户。

## 实战经验与避坑（Playbook）

**分辨率/能力**
- **1K 与 1.5K 同价 → 永远用 1.5K**；`pro` 最高 2K；**4K 需 `4.0`（`-4-0-20260415`）**；联网搜索仅 `lite`。

**模型选择（诚实版：证据不足，用策略而非猜测）**
- 同提示词下 **pro 不必然更好**（实测三种题材胜负反转）。决定因素是 **(命中率 p, 单价 c)**：期望成本/可用图 ≈ `c / p`。flash 更划算 ⟺ `p_pro / p_flash < 2.5`（1.5K；2K 要 <5）。
- **可辩护的策略**：默认 `flash`；**能力硬需求**（精确编辑/图层/高保真成片）直接 `pro`；否则先 flash 抽 1–2 张——**结构类失败**（肢体/构图/多主体）才升级 pro，**审美不讨喜**则继续 flash 重抽，别升级。
- **模型选择是二阶杠杆**：提示词质量、构图/姿态、抽卡预算（`-n`）才是一阶。（n=39 实测：默认 `flash` 成立——通过率接近、审美不输、`c/p` 便宜 2.2×）

**提示词**
- 官方：**自然语言连贯句 > 关键词堆叠**；**无负向提示词**；≤300 汉字；**无权重语法**；画面内文字用**双引号**。
- 已具体 → 少改；很模糊 → 才补 构图/光线/风格；**"更长 ≠ 更受控"**——长的"保持…不变"清单**锁不住主体**，反而可能漂移。
- **出图前先确认**：清理器 / AI 写的提示词可能是雷——**别把"交代清楚"直译成"画清楚 / 细节"**（实测 → 女孩丢袜子）；走 Ask Gate 让用户拍板（见 `seedream-prompt-compiler` R4.8）。

**构图/姿态/易错项**
- 补"**景别/全身**"能提升**姿态完整度**（实测有效）。
- **换背景必须交代"姿态 × 环境"**（编译器 R4.6）：保姿态选相容环境，或明确改姿态。
- 手/肢体 → **正向写清 + 遮挡/景别规避**，**别写"不要搞错"**。
- **文字**：当文字是**画面主体**（海报/招牌）时，**长中文 + 阿拉伯数字实测还原很好**（8/8），**双引号非必需**；只有**微小道具文字**（书封面/二维码）才不可靠。要清晰文字就重生成。

**编辑 / 图生图**
- **分割/抠图很强**（发丝、铁丝网孔、指缝都干净）；难点在**场景语义**（物理合理性），不在抠图。
- 保身份细节 → **flash + 极短提示**；要真实观感 → **pro + 详细**，接受主体被重画。
- 输入图按 0.02 元/张另计（pro，首张免费）。

**降废片工作流**
- 生图是**抽卡**：用 `-n N` 一次多出再挑；想要可复现就 `--seed` + `--save-meta`。
- 出错优先 **换 seed / 切 pro / 用编辑**，**不要靠加重提示词**。
- 生成后**自检已知失败模式**（肢体、文字、姿态逻辑）再定稿。

**评估注意**：图像评估模型对**逻辑/物理穿帮不敏感**（如"坐地上却摆在椅子前"没抓到）→ 这类问题**靠人看**，或在提示词阶段用 R4.6 提前规避。

**实测边界（2026-10，n 小、勿当定论）**：模型**基础能力很高**，`raw vs compiled`、`optimize ON vs OFF` 的差异**常落在噪声内**（多轮实验通过率都接近 100%）。→ 别指望提示词微观操作带来大幅提升；真正的质量杠杆是 **best-of-n 抽卡挑最佳（审美）** 与**选对场景/构图**。

**失败模式现状（2026-10 陷阱测试）**：**肢体/手指崩坏已基本消失**（手势形态 12/12 正常）；剩余失败集中在**语义精度**——**数量数错、左右手弄反、动作语义跑偏**。这类**不是提示词能稳定修的**，靠 **pro（结构精度更稳）/ 多抽 / 后期编辑**。（C2 实测：自然 / 强调整数 / 显式枚举三种措辞对计数**无差别** 12/12、左右手 3~4/4、解剖崩坏 0/24 → **语义精度是抽样问题，改措辞无效，只能多抽挑正确或上 pro**。）

## 带自检的出图（Quality Loop）

重要图片、或用户要求“带自检 / 保证质量 / 降低废片”时，走 `seedream-qc` 的闭环：
**编译 → 生成 → @observer 按失败模式评分 → 不合格则只改一处（换 seed / 改提示词 / 切模型）重抽（默认封顶 2 次）→ 交付最佳**。
日常出图不必走闭环（废片率本来不高）。

## 注意事项

- 图片生成是**付费**操作；一次一图，不要擅自批量刷图。
- 失败时先看脚本输出：`HTTP 401` = Key 无效；`HTTP 403/404 model` = 模型未开通或 ID 不对；`HTTP 429` = 触发限流（脚本会自动重试）。
- 不要在对话或命令里回显、硬编码 API Key；脚本只从环境变量读取。
- 本技能明确属于**内容创作**任务，不要用于修改代码或系统配置。

## 同账号姊妹能力：视频（Seedance）｜未接入

同一 `ARK_API_KEY` 也可生视频，但**开通门槛：账户余额 > 200 元**（或 ≥200 元节省计划 / 资源包），本机暂未接入。备用要点：

- **可开通模型**：`doubao-seedance-2-5-260628` / `2-0-260128` / `2-0-fast-260128` / `2-0-mini-260615` / `1-0-pro-fast-251015`。
- **异步接口**：`POST /api/v3/contents/generations/tasks` 建任务 → 轮询 `GET .../tasks/{id}` → 取 `content.video_url`（**24h 有效，须下载**；任务记录保留 7 天）。
- **计费**：`token单价 × token用量`，`token ≈ 帧数 × 宽×高/1024`（帧数 = 时长×24）。
- **参考价（纯生成）**：5s 720p ≈ mini 2.48 / fast 3.99 / 2.0 4.97 / 2.5 7.56 元；**mini/fast 仅 720p**；**4K 仅 2.0**；2.5 支持 30s + 音频。
