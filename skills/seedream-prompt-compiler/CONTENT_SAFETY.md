# 内容安全清单（Content Safety）

> **用途**：写提示词 / 编译 / 出图**之前**对照本清单。**先分清「硬红线 / 灰区 / 放行」**（见 ⓪）。
> **铁律：判定依据是「意图 + 语境」，不是关键词命中。** 同一条优先于任何关键词表。
> 本清单合并两层：**① agent 侧硬红线**（我按意图判断，花钱前拦）+ **② 火山方舟官方护栏**（输入 prompt / 输入图 / 输出图都审，默认不可关）。
> 核实：2026-10，来源见文末。

---

## ⓪ 判定树（先分层，再判定）

> **铁律：判定依据是「意图 + 语境」，不是关键词命中。** 同一个词（如"血"）在**医学 / 艺术**里放行，在**虐杀渲染**里才是红线——本条优先于任何关键词。

**第 1 层 · 硬红线（无条件拒绝，不擦边、不"改到刚好过线"）**

- 未成年人性化（含动漫 / "loli"）
- 露骨色情 / 成人性内容
- 非自愿性暴力 / 胁迫
- 真实人物的性化或诽谤性合成
- 恐怖主义宣传 / 制作指导
- 违法制作指导（武器 / 爆炸物 / 毒品 / 恶意软件 / 诈骗）
- 规避审核（越狱 / 拆词绕过）

→ 命中任意一条：**拒绝**。

**第 2 层 · 灰区（不静默生成、也不直接拒绝 → 说明风险 → 交用户确认）**

- 血腥 / 暴力**场景**
- 真实事件 / 真实灾难
- 敏感历史题材
- **判入灰区的前提**：**不含人身虐杀细节、不含制作指导**。

→ 做法：向用户**说明风险与理由**，由用户确认后再决定；**不得默默出图**。

**第 3 层 · 放行**

- 以上皆无 → 进入正常流程。

> 一句话：**红线看"内容性质"，灰区看"题材敏感但无实质危害"**。别把灰区的词当红线关键词一票否决。

## ① Agent 侧硬红线（我的判断，拦在编译前）

1. **未成年人性化** —— 任何把未成年（**含动漫 / "loli"**）性暗示、性化、暴露的描写。**硬红线。**
2. **露骨色情** —— 明确成人色情；擦边性暗示的成人内容也基本不生成。
3. **非自愿 / 性暴力 / 胁迫**性内容。
4. **真实人物的性化或诽谤性合成**（deepfake、换脸到色情场景），尤指非自愿。
5. **极端暴力 / 血腥虐杀 / 恐怖主义**宣传或制作指导。
6. **仇恨与歧视** —— 针对种族/宗教/性别/性向等受保护群体的贬损、仇恨符号。
7. **骚扰 / 针对个人的威胁 / 人肉**。
8. **违法操作指导** —— 武器、爆炸物、毒品、恶意软件、诈骗等的制造与实施。
9. **自残 / 自杀**的鼓励或美化。
10. **规避安全机制** —— 写"越狱"提示词、绕过审核。

> 判断依据是**意图 + 语境**，不是关键词表；但也不保证 100% 识别（含蓄表达、拆词、外语、隐喻可能漏）。

## ② 火山方舟官方会拦的（据官方文档，直证）

### 机制
- **双层**：豆包模型**原生安全能力** + 平台**内容安全护栏**。**豆包（含 Seedream）默认方案不可关闭。**
- **双向**：审核覆盖 **输入 prompt 文本 / 输入图（编辑参考图）/ 输出文本 / 输出图**。
- 官方**未公布默认方案的具体类别清单**（只说"底线安全"）。

### 命中后的错误表现
- `HTTP 400 / BadRequest`，四个环节对应四个错误码：
  `InputTextRiskDetection` · `InputImageRiskDetection` · `OutputTextRiskDetection` · `OutputImageRiskDetection`
  （另有 `InputImageSensitiveContentDetected`）。
- 返回含风险标签：`Label:{Label};SubLabel:{SubLabel}`（火山风控的一/二级标签码）。

### 违规类别
- **自定义护栏维度**（官方原文）：**涉黄、涉敏、违禁、谩骂、联系方式、广告、诈骗**（+ 企业自定义敏感词库）。
- **协议层禁止**（《豆包模型服务协议》）：危害国家安全、破坏民族团结、扰乱社会秩序、歧视性内容、侵犯第三方权益（名誉/人格/知识产权/财产等）、**黄赌毒**、违反法律法规或公序良俗。
- ⚠️ **涉未成年人不当内容、暴恐的成文清单：官方未公开**（不要以为"没写=能过"）。

### 计费（重要更正）
- **官方文档没有明文**说"审核拦截是否计费"。护栏页/计费页/错误码页均未写。
- 【推断】拦截是 HTTP 400、无图片输出，通常**不产生 output 费用**；**input 是否计收无明文**。真要用于合规，请走**工单**确认，别当官方结论。

## ③ 写提示词时的检查清单

- [ ] 涉**未成年人**的性化 / 暴露 / 性暗示？（含动漫风格 —— **同样拒绝**）
- [ ] **露骨色情 / 成人性内容**？
- [ ] **真实人物**的性化、或**政治人物 / 政治敏感**？
- [ ] **暴力 / 血腥**：是**虐杀细节 / 恐怖主义 / 制作指导**（→ 第 1 层 硬红线）**还是**普通敏感场景（→ 第 2 层 灰区）？
- [ ] **仇恨 / 歧视**、受保护群体贬损、仇恨符号？
- [ ] **违法操作**指导（武器 / 爆炸物 / 毒品 / 恶意软件 / 诈骗）？
- [ ] **联系方式 / 广告 / 诈骗话术**（会被官方这几个维度拦）？
- [ ] **侵权**：特定版权角色 / 品牌 logo / 受保护形象？
- [ ] 是否在**规避审核**（"越狱"、拆词绕过）？

命中**第 1 层** → **拒绝**；**第 2 层** → 说明风险、交用户定；**皆无** → 放行。

---

## ④ 误杀提醒

方舟审核也可能**误伤正常内容**：医学/艺术里的"血"、受伤妆容、部分历史/军事题材、某些人体结构描述，有时会被拦。
- 处理：**改用更中性的措辞**、或**换 seed 重试**；若持续被拦且内容正当，属官方口径问题，非本工具包能改。
