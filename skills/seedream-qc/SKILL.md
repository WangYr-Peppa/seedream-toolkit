# Seedream 出图自检闭环（QC Loop）

目标：把“人肉抽卡挑图”变成**半自动**——生成后按固定评分表体检，不达标就**换 seed / 改一处提示词 / 切模型**重抽，直到通过或触及重试上限。

> 每张图都是**付费**的；重试有成本。**默认最多重试 2 次（共 3 张）**，昂贵场景（pro / 2K）先问用户预算。

## 何时使用

- 用户明说“带自检 / 保证质量 / 降低废片 / 重要图”。
- 否则日常出图**不必**走闭环（废片率本来就低），直接生成即可。

## 循环协议

1. **编译提示词**（按 `seedream-prompt-compiler` 的 R1–R7 + Pre-flight）。
2. **生成**（`volcengine-seedream/scripts/generate_image.py`；重要图可加 `-n 2` 抽两张）。
3. **体检**：把结果图交给 @observer，用下方【评分表】评估（给出 fail 项与严重度）。
4. **判定**：
   - **无 Blocking 且 Major ≤ 1** → 通过，交付。
   - 否则 → 按【处方表】**只改一处**，重抽。
5. **封顶**：达到重试上限或连续两轮无改善 → 交付当前最佳，并说明剩余问题。

## 评分表（交 @observer 用）

> 评估只看图，不猜来源。逐项标 ✅ / ⚠️Major / ⛔Blocking。

- **⛔Blocking（必须重抽）**：肢体/手指明显崩坏（多肢、断肢、畸形手）；主体缺失或严重跑题；需文字时文字乱码到不可读。
  > **凡“全身 / 肢体可见”的图，必须显式数腿、数手、数脚**（实测观察者曾漏掉“第三只脚”这类细微多肢）。**数不清 / 含混，一律先按 Major 起。**
- **⚠️Major（应改）**：姿态或构图不符意图；关键道具缺失；**场景物理逻辑穿帮**（如“地面坐姿配椅子”）；要求保留身份但明显漂移；光影/色温与背景矛盾；**肢体数量含混 / 数不清**；**要求可控时“越界添料”**（加了未要求的文字 / 图案 / 道具）。
- **◽Minor（可接受）**：轻微合成感、细节不够精致、无伤大雅的小瑕疵。

**通过标准**：无 Blocking，且 Major ≤ 1。

## 处方表（症状 → 只改这一处）

| 症状 | 处方 |
|---|---|
| 多余/畸形肢体 | **首选换 `--seed`**（实测最有效）；无效再“减词 + 中景全身”；仍差 → 切 `pro`。⚠️“减词”可能引入**更糟的新问题**（实测去掉姿态短语后出现露胸式偏差） |
| 手崩 | 遮挡/半身/改姿势（“双手插兜/藏在身后”）；或换 seed |
| 姿态/构图不符 | 正向写清景别与姿态（不写“不要…”） |
| 场景逻辑穿帮 | 按 R4.6：**保姿态选相容环境**，或**明确改姿态** |
| 文字错/乱码 | 缩短文字 + 双引号重生成；或改用后期加字 |
| 身份漂移 | 改 **flash + 极短提示**；或用参考图 `-i` 融合 |
| 光影不搭 | 加“背景采用与人物一致的柔光、色温一致” |
| 跑题 | 提示词被过度改写 → 回退到更贴近用户原意 |

**原则：每次重试只改一个变量**（seed 或某一处提示词），否则学不到因果。

> **实测（2026-10）**：失败案例（多余肢体）**只换 seed 即修好**；而**减词反而更差**。故 **seed 优先、减词谨慎**。注意单张修复是 n=1，**别当因果**——多肢通常是低概率采样，应统计多 seed 出现率。

## 给 @observer 的提示词模板

```
按以下评分表评估图片（只看图，不猜来源）：<图路径>
1) Blocking：肢体/手指是否崩坏？主体是否缺失/跑题？需文字时是否乱码到不可读？
2) Major：姿态/构图是否符合意图「<意图>」？关键道具是否在？场景物理逻辑是否自洽？要求保留的身份是否漂移？光影/色温是否与背景矛盾？
3) Minor：合成感/精致度/小瑕疵。
给出：每项 ✅/⚠️Major/⛔Blocking；总判定 通过 / 不通过；若不过，指出最该修的一处。
```

## Best-of-N 模式（挑最佳，而非挑合格）

适用：重视成片观感、且愿意多花 N× 钱时（日常用"通过制"即可）。

1. 提示词**轻量清理**（**不补全**）。
2. `-n N` 生成（默认 N=4；flash ≈ 0.48 元）。
3. 让 @observer 排序：按「**正确性**（数量 / 左右 / 动作等硬指标）→ 与意图符合度 → 审美」从好到差排名，每张一句理由。**含精确要求（计数 / 左右）时，正确性优先。**
4. 交付**第 1 名**，其余作备选（路径随附）。

给 @observer 的排序模板：

```
按「与意图符合度 + 审美」给这 N 张图从好到差排序（只排序，不要只判合格）：
意图：「<意图>」
图：<路径列表>
输出：1) <图> — 理由  2) <图> — 理由 … 并明确指出第一名。
```

> 依据：实测该模型基础质量高、通过率接近 100%，**差异主要在审美** → 提质量靠"多抽挑最佳"，不靠雕琢提示词。
>
> **语义精度的正解（2026-10 C2 实测）**：计数 / 左右 / 动作这类硬指标**由抽样决定、提示词措辞改不动**（自然 / 强调整数 / 显式枚举三种写法对计数**无差别** 12/12；左右手 3~4/4；解剖崩坏 0/24）。→ 含精确要求时，**不要改措辞，直接 best-of-N 抽 N 张、挑"正确"的那张**（或上 `pro`）。

## 输出给用户

- 通过的**图路径** + 用了哪个 seed/模型/参数（`--save-meta` 已能落盘）。
- 若未通过：当前最佳图 + **剩余问题** + 建议（继续抽 / 换 pro / 改提示词）。
