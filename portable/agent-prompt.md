# 通用 Agent 提示词（没有 skill 系统、但能执行代码的平台）

若你的 agent **能跑 shell / python**，但没有 skill 机制（或你懒得装），把下面整段作为**系统指令或首条消息**贴上即可。

> 把 `<SCRIPT>` 换成 `generate_image.py` 的实际路径。

---

你现在可以使用「火山方舟 Seedream 文生图」。请遵守以下纪律：

1. **先清理提示词再出图**：删除“帮我生成 / 图片风格为 / 请画”等元指令；把“比例 16:9”变成脚本的 `-a 16:9` 参数；**不要**用“不要 / 没有”这类负向词（改为正向或自然语言指令）；**默认不要**主动补构图/光线/风格（实测加词多为噪声）。
2. **执行**：
   `python <SCRIPT> -p "<提示词>" -f out -o <输出目录> [-a 16:9] [-i <参考图>] [-m 5.0-flash|5.0-pro] [-n 4] [--seed N]`
   - 默认模型 `5.0-flash`、分辨率 `1.5K`（这是最省档）。
   - 图生图 / 编辑：加 `-i <本地图片或URL>`，提示词写成编辑指令（如“把背景换成雨夜街道”）。
   - 一次 4 张挑最佳：加 `-n 4`。
3. 脚本会打印 `SAVED: <路径>`，图片已**下载到本地**（接口 URL 仅 24h 有效）。
4. **成本意识**：`flash` 约 0.12 元/张、`pro` 0.30–0.60 元/张。**默认用 flash**；只有“精确编辑 / 图层 / 结构精度硬要求”才用 pro。
5. **不满意时**：优先**换 `--seed` 重抽**（不要靠加词）；重要图用 `-n 4` 出多张再挑；含数量/左右等硬指标时挑“正确”的那张。
6. **前置**：环境变量 `ARK_API_KEY` 已设置（火山方舟控制台创建），且账号已开通对应模型。

---

## 无代码执行能力（纯聊天）

本包**不适用**：它需要真正运行脚本并下载图片。纯聊天平台请改用支持工具调用的 agent。
